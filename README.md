# The Robot Vacuum's Best Excuse

A robot vacuum's one-line excuse for missing a spot — written in its own voice, rooted in its world of socks, chargers, and survival instincts. The program writes the excuse to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), validated as a single line of at most 140 characters including the trailing newline.
